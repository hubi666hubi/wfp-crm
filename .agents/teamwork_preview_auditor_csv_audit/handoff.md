### Challenges

#### [Low] Challenge 1: Empty and malformed fields handling
- **Assumption challenged**: Assumes CSV data contains populated fields for critical columns like Company and Email.
- **Attack scenario**: An input row has both Company and Email fields completely empty.
- **Blast radius**: The row has empty strings for keys, and will group with other empty rows under the graph deduplication step.
- **Mitigation**: The code filters out empty rows and uses conditionals `if comp:` and `if email:` before adding to adjacency lists, ensuring empty fields do not cause incorrect merges.

#### [Low] Challenge 2: Currency formatting with commas
- **Assumption challenged**: Assumes that currency amounts like `"$25,000"` are read using standard CSV parser rules.
- **Attack scenario**: Raw string parsing might split the field on commas.
- **Blast radius**: Inaccurate lead value statistics and broken output schemas.
- **Mitigation**: Verified that the code uses `csv.reader` instead of naive split, which handles quoted commas correctly.
